## Read an explanation in four passes

Open an employee assignment and ask:

1. **Source:** Which stable policy and exact version supplied the value?
2. **Origin:** Did the policy match directly or arrive through a group?
3. **Evidence:** Which employee facts satisfied the rule, or which explicit group supplied it?
4. **Selection:** What field, cardinality, strategy, and priority determined the outcome?

## Avery's resolved result

| Field | Final value or values | Explanation |
| --- | --- | --- |
| Pay schedule | Bi-weekly | California state matched; priority 20 beat the Semi-monthly candidate at 10 |
| Vacation policy | Standard PTO | Full-time matched Standard PTO |
| Application access | 1Password, GitHub, Linear | Security Baseline matched directly; Engineering Access came through the Engineering group; the many field combined unique values |
| Compliance training | CA Workplace Harassment | California state matched California Compliance |
| Equipment stipend | $1,000 annual | Engineering department matched Engineering Equipment |

The most important sentence is not “this policy matched.” It is “this exact policy version supplied this value through this origin, and this field's strategy selected it.”

An explanation is stored as an immutable snapshot. If its material evidence changes, assignment history can gain a new row even when the visible value stays the same.
