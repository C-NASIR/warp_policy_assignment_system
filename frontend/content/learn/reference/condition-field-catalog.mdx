The policy builder retrieves an allowlisted catalog rather than accepting arbitrary field names. Each entry defines its display label, permitted operators, input type, and dependencies.

Static fields include trusted employee attributes such as state, department, employee type, location, start date, and manager. Derived entries cover supported tenure and reporting-organization facts.

Use the builder as the live catalog because available operators and input controls come from the backend. Dependencies tell reconciliation which workforce changes can affect a result.
