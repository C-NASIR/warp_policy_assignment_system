Search filters event text by actor or change summary. Entity and action filters narrow the recent append-only event set. The table shows when, actor, entity, action, and summary; all times are UTC.

Expanding a row shows a technical record reference and formatted before/after payloads. Audit records administrative change, not the complete temporal assignment answer—use employee assignment history for that.
