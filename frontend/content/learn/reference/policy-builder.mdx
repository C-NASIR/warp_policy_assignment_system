**Policy basics** contains the stable name, numeric priority, and inclusive effective dates. A successor version can close a prior open-ended range.

**Conditions** supports ALL or ANY logic, additional rows, and one nested group. Fields expose their valid operators and input controls. **Assignments** selects a configured output field and value; multiple rows can target multiple outputs.

Eligible roles may appear as automated-access outputs. These can change whether independent approval is required. The impact panel distinguishes matches from resulting assignment changes. Editing the proposal invalidates the prior preview.
