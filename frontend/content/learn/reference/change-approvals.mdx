The approval queue lists persisted sensitive requests with author, operation, status, expiry, impact, and exact change details. Request capabilities determine whether the current user can approve, reject, or execute.

The author cannot approve their own request. Approval records authorization; the approving user then executes the exact request. Rejected, expired, stale, or already executed requests cannot be repurposed for changed input.

Not every preview enters this queue. Ordinary supported changes may execute directly from a short-lived preview token.
