The assignment-field catalog supports name search and cardinality filtering. Each definition is either **One value** or **Many values**.

One fields use priority to select one result and can conflict at equal winning priority. Many fields retain unique values. Cardinality is fixed after creation. Creating a definition does not create employee assignments; effective policies or overrides must supply values.
