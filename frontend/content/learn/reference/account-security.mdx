**Multi-factor authentication** enrolls a TOTP authenticator and displays one-time recovery codes. Disabling MFA requires the current password and authenticator code.

**Password** changes require the current password and sign out other sessions. **Confirm your identity** establishes recent reauthentication for sensitive actions.

**Active devices** shows current sessions and can revoke other or all devices. **Security events** records sign-in and account changes; actionable events can be acknowledged after review.
