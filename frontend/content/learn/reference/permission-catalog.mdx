| Area | Read or entry | Change authority |
| --- | --- | --- |
| Employees | `employees:read` | `employees:create`, `employees:update` |
| Assignments | `assignments:read` | `assignments:manage` |
| Policies | `policies:read` | `policies:create`, `policies:version:create`, `policies:activate`, `policies:archive` |
| Groups | `groups:read` | `groups:create`, `groups:update` |
| Approvals | request capability | `changes:approve`, `changes:execute` |
| Configuration | `settings:read` | `settings:manage` |
| Audit | `audit:read` | Read only |
| Access | `access:read`, `access:review` | `access:manage` |

`changes:preview` authorizes supported impact previews. A policy record can further restrict lifecycle/version actions through calculated capabilities. Employee and assignment-field scopes independently restrict visible data. The root wildcard `*` grants all actions but should remain exceptional.
