Do not retry with altered input or try to reuse the old authorization. Return to the source workflow, load current state, and preview the complete proposal again.

Compare the new impact with the expired or stale request. Submit a new persisted request when the operation requires independent approval. A different authorized person reviews it, then approves and executes that exact payload.

The replacement trail preserves why the original request was not executed.
