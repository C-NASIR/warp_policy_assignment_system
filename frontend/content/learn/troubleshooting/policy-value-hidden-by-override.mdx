Open the employee and expand the affected assignment. An override source identifies the immutable exception and the policy results it replaced.

In **Manual overrides**, verify the field and current manual value. If the exception is no longer intended, use the delete action and review impact before confirming. The preview shows values current policies would restore; it does not simply reuse the old assignment.

Keep the override when it is still an authorized exception, and use its audit trail to confirm ownership.
