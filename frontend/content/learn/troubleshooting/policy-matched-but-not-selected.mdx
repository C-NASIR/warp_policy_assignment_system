1. Confirm the output field and candidate value on the effective policy version.
2. Check the field cardinality. For `one`, compare all priorities; only the highest wins. For `many`, different unique values remain.
3. Inspect whether another source supplied the same many-value result and became its recorded provenance.
4. Check the employee for an active field-level override, which replaces all policy results after resolution.
5. Expand the current assignment explanation and compare candidates with the selected source.

“Matched” describes applicability. “Selected” describes the later resolution outcome.
