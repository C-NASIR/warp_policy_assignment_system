Compare the retired and current history rows. Check policy version, origin, matched evidence, priority, candidate selection, and override source.

PolicyOS can open a new row when the material explanation changes even if the visible value string is identical. This preserves which rule and evidence justified the answer over time.

Use nearby audit events to identify the action that changed the source or evidence.
