Check that the stable policy is active and the expected version's inclusive date range contains the evaluation date. Look for a deliberate gap; versions cannot overlap, but gaps are allowed.

Distinguish a future calculation from today's persisted assignment. Viewing a prospective answer does not make it current. On the boundary date, confirm scheduled reconciliation has run and inspect current employee evidence.

If the prior version was open-ended, verify the successor start date closed it on the preceding date.
