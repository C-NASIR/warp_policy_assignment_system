## Choose cardinality first

Open **Assignment fields**. Decide whether an employee should have one resolved value or a set of unique values. Use `one` for outputs such as Pay schedule; use `many` for outputs such as Application access.

Enter a durable, user-facing name, choose the cardinality, and create the field. Cardinality cannot be changed afterward, so confirm the resolution model before saving.

The new field is only a definition. It produces no assignments until an effective policy version supplies values or an employee receives an override.
