## Narrow the event set

Open **Audit log**. Search actor or change text, then filter by entity and action. Timestamps are shown in UTC. Use the entity label and technical reference to distinguish records with similar names.

Expand an event to compare its before and after payloads. Follow a sequence by actor, entity, and time rather than assuming one event contains an entire workflow.

For “what assignment was true?” switch to the employee's assignment history. Use audit for administrative actions and accountability; use history for the temporal outcome.
