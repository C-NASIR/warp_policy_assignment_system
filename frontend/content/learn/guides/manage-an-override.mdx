## Create or change

Open the employee's **Manual overrides** panel. Choose **Add override**, or edit an existing one. Select the assignment field, enter the complete manual value, and choose **Review impact**.

Confirm the preview identifies every policy result the exception will replace. For a many field, the override replaces the whole set. Choose **Confirm and reconcile** only when the exception is intentional.

## Remove safely

Use the delete action, preview which policy values will return, then confirm. Removing an override restores current resolution; it does not restore a hard-coded old value.

Review current assignments, history, and audit afterward. If PolicyOS reports a policy conflict, resolve that conflict first—an override cannot hide it.
