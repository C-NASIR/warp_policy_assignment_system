## Design from the job

Open **Access control**, select **Roles**, and choose **Create role**. Name the job responsibility, then select only its required action permissions.

Set employee visibility independently: none, linked employee only, reporting tree, or all. Set assignment-field access independently: none, selected fields, or all. Test both boundaries; action permission alone does not establish record visibility.

Enable **Allow policies to grant this role** only for safe, narrowly scoped roles that should be automated. Roles containing protected high privilege are rejected for automation.

Save the role, assign it to a test user, and verify the user can reach required workflows without gaining unrelated data.
