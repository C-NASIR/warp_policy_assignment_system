## Three query modes

For **today**, PolicyOS reads the persisted current assignments produced by reconciliation. For a **past date**, it reads recorded assignment history. For a **future date**, it evaluates expected policy behavior without persisting the result.

That difference changes the evidence available. A historical answer reflects what PolicyOS actually recorded, including the source and explanation at that time. A future result is prospective and can change if employee facts, policies, groups, or overrides change before the date arrives.

The current frontend focuses on current employee assignments and recorded history; it does not provide a batch future-query workflow. Treat a preview or future API answer as a forecast, not proof that current state changed.
