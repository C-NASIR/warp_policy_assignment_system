## Read the canonical tree

An **ALL** group matches when every child condition matches. An **ANY** group matches when at least one does. Nested groups let authors express combinations such as “Full-time AND (California OR Oregon).” The builder and saved version preserve this canonical tree, even though the engine compiles it to an equivalent OR-of-AND form for evaluation.

## Derived facts

PolicyOS exposes only allowlisted derived fields. Tenure is calculated from the employee start date and evaluation date. Organization fields use reporting relationships, such as whether an employee reports within a manager's tree. Their dependencies are explicit so a relevant employee change can trigger reconciliation.

Use the field's available operators and input type. Do not type an unsupported field name or assume arbitrary employee data is available to rules.

When investigating a match, read the explanation's satisfied clauses alongside the original tree. A compiled clause is evidence of the same authored logic, not a different policy.
